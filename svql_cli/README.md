# svql_cli: Command-Line Interface

**Purpose**  
User-facing command-line tool for executing SVQL pattern matches against hardware designs. Provides argument parsing, query registration, execution orchestration, and formatted output (text, CSV, LaTeX) for security auditing and design analysis.

## Core Abstractions

| Type | Description |
|------|-------------|
| **`Args`** | Clap-derived struct defining CLI arguments: design specs (`-d`), query selection (`-q`), output formats (`--output-csv`, `--output-latex`), and flags (`--profile`, `--parallel`). |
| **`DesignSpec`** | Parsed design specification containing path, module name, raw import flag, and match length strategy. Supports sub-flags via shell-word parsing. |
| **`QueryArg`** | Enum of registered query types (Cwe1234, Cwe1271, Cwe1280, etc.) generated by `register_queries!` macro. Implements `ValueEnum` for clap integration. |
| **`QueryMetrics`** | Per-query execution results: name, design path, match count, timing, memory delta, and result store reference. |
| **`register_queries!`** | Procedural macro mapping enum variants to concrete pattern types from `svql_query_lib`, generating dispatch logic. |

## Architecture

**Execution Flow**  
```
Command Line Args
    ↓
Args::parse() (clap)
    ↓
DesignSpec::to_config() (per-design configuration)
    ↓
Driver::new_workspace() (initialize design cache)
    ↓
For each DesignSpec:
    Driver::get_design() (load/index)
    ↓
    For each QueryArg:
        QueryArg::run() (dispatch to Pattern::search)
        ↓
        Collect QueryMetrics
    ↓
Output Results
    ├── Console (tables, trees)
    ├── CSV (export_csv)
    └── LaTeX (export_latex)
```

**Query Registration**  
The `register_queries!` macro generates:
- Enum definition with `#[derive(ValueEnum)]` for clap integration.
- `all()` method returning all variants.
- `name()` method returning string representation.
- `run()` method implementing the dispatch logic:
  1. Preload driver dependencies.
  2. Execute `Pattern::search()`.
  3. Collect metrics (timing via `Instant`, memory via `sysinfo`).
  4. Return `QueryMetrics` with results.

## Key Implementation Details

**Design Specification Parsing**  
- Supports complex sub-flags: `-d "design.json --module top --raw --match-len exact"`.
- Uses `shell_words::split()` to parse quoted arguments within the design spec string.
- Each design maintains independent configuration (raw import, match length) while sharing global flags (parallelism).

**Profiling & Metrics**  
- **Timing**: `std::time::Instant` around query execution.
- **Memory**: `sysinfo::System` to capture RSS delta (MB) before and after execution.
- **Gates**: Cell count from `GraphIndex::num_cells()` for LaTeX table generation.

**Output Formats**  
- **Console**: ASCII tables with Unicode box-drawing characters showing query, design, matches, time, and memory.
- **CSV**: Standard CSV with headers (design_path, design_module, query_name, matches, execution_time_ms, etc.).
- **LaTeX**: `tabular` environment using `multirow` package to group results by design; includes gate counts and formatted metrics.

**Parallel Execution Control**  
- Global `-p` flag enables `rayon` parallelism in both the CLI (across designs/queries) and the query engine (within pattern matching).

## Integration with Ecosystem

- **Depends on**: `svql_driver` (design loading), `svql_query` (execution engine), `svql_query_lib` (pattern definitions), `svql_common` (configuration types).
- **Entry Point**: `main()` initializes tracing, parses args, initializes driver, executes queries, and renders results.
- **Extensibility**: New queries are added by modifying the `register_queries!` invocation in `args.rs` to include additional pattern types from `svql_query_lib` or user crates.

## Usage Examples

**Basic Usage**  
```bash
# Run all registered queries on default design
cargo run -p svql_cli

# Run specific query on custom design
cargo run -p svql_cli -- \
  -d "examples/designs/soc.json --module top" \
  -q cwe1234

# Run multiple queries with profiling
cargo run -p svql_cli -- \
  -d "design.json -m top" \
  -q cwe1234 -q cwe1280 \
  --profile -p

# Export results to CSV and LaTeX
cargo run -p svql_cli -- \
  -d "design.json -m top" \
  --output-csv results.csv \
  --output-latex results.tex
```

**Programmatic Query Registration**  
```rust
// In src/args.rs
register_queries!(QueryArg {
    Cwe1234 => svql_query_lib::security::cwe1234::Cwe1234,
    Cwe1271 => svql_query_lib::security::cwe1271::Cwe1271,
    Cwe1280 => svql_query_lib::security::cwe1280::Cwe1280,
    // Add custom queries here
});
```
